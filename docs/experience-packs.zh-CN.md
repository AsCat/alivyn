# 意续体验包

状态：第一条性格与经历链路已实现；感官、设备行动和独立人物实例尚未实现。

## 当前可体验

`natural` 和 `vivid` 是**同一个意续的性格表达**。`natural` 沿用原有性格；`vivid` 增加具体的偏好、矛盾心思和情绪余波。两者之间切换不改变名字、汐湾世界、聊天记忆与联系边界。

`dafeiyu-astrbot` 是独立客串角色，使用上游公开的 AstrBot v2.1 人设原文，必须放在单独的 `ALIVYN_HOME`；程序会阻止在已有记忆的目录里从意续切成客串角色。它只提供角色文本体验，完整上游插件和虚拟手机能力并未接入。来源、许可和试用边界见[大肥鱼原始人设试用](dafeiyu-trial.zh-CN.md)。

```sh
alivyn persona pack list
alivyn persona pack set vivid
alivyn persona pack show
```

正在运行的渠道要重启才能读到新配置。`character_v2` 在已送达对话后异步整理短时状态；现在还可以选取有来源的重要交流，记录事件、人物自己的反应和可修正的理解。以后生成回复时最多带入最近八条这样的经历。普通招呼不必产生经历。遗忘个人信息或重置人物时，派生的经历随来源一同清理。经历是叙事记忆，不是模型原始思维链。

鲜活包可在 `character_v2` 的飞书私聊中把一轮回复分成两到三条短气泡，仍作为一次逻辑回复保存。每条气泡的发送进度单独落盘；确定成功发送的前段不会在后段失败后被整段重发。发送成功与落盘之间若发生进程崩溃，平台未提供本接口可用的气泡级幂等键，仍可能重发最后一段。

用隔离场景比较，不改正在运行的角色配置，也不发送真实飞书消息：

```sh
ALIVYN_AUDITION_PACK=natural alivyn actor audition character_v2 "bad day"
ALIVYN_AUDITION_PACK=vivid   alivyn actor audition character_v2 "bad day"
```

## 后续能力接入

1. **人物实例边界**：新增独立人物时给配置、世界、记忆、关系和渠道绑定单独的实例 ID；不同人物不共用过去。当前性格包只改变同一人物的表达。
2. **感官与表达**：在渠道适配层加入图片、语音输入、语音输出和表情；模型可以由用户自行选择，能力缺失时不声称已经看见或听见。
3. **行动与生活**：将网页和虚拟手机作为显式授权的工具，保存操作结果并转成可追溯生活事件；主动联系只能引用真实记录或明确的虚构世界事件。
4. **可视化**：桌宠和仪式化人物内部视图作为客户端消费同一个状态引擎，不另造记忆与人格。

社区“大肥鱼”是多个独立开源实现共享的二创形象。此处借鉴可验证的技术机制；意续的提示词和角色形象独立创作。[人格预设素材边界](https://github.com/linsport/dsh-whale-persona/blob/main/LICENSE)与[另一实现的第三方素材说明](https://github.com/SAKURAfan1023/dafeiyu-bot/blob/main/THIRD_PARTY_NOTICES.md)都指出代码许可不自动覆盖视觉形象。
