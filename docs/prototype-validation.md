# Foundation prototype validation

Updated on 2026-10-24. These are local preview checks, not a stable product release.

| Path | Result | What it establishes |
| --- | --- | --- |
| `go test ./...` | Passed | Mock model responses, persistent conversation and source-linked memory, private local file permissions, three scenario replays, and a durable contact loop with policy, failure, restart, and concurrency checks. |
| `go vet ./...` | Passed | No current Go static-analysis findings. |
| `go run ./cmd/alivyn version` | Passed on macOS arm64 | CLI starts under Go 1.26. |
| `go run ./cmd/alivyn doctor` | Passed on macOS arm64 | Pure-Go SQLite can create, insert, and read a temporary database. |
| `go run ./cmd/alivyn tui` | Passed in a local macOS terminal | The continuous conversation renders and exits with Esc. Unit tests cover saved history after reopening and visible model errors. |
| `bash scripts/tui-smoke.sh` | Passed on macOS arm64 | Starts the actual TUI under a pseudo terminal and verifies the AI identity header; the same check runs in macOS and Ubuntu CI. |
| `go run ./cmd/alivyn demo` and `demo en` | Passed on macOS arm64 | The bilingual disposable SQLite runtime corrects an interview date, stays silent on Wednesday, follows up on Friday, greets after a long gap, and suppresses a repeated greeting. |
| `go run ./cmd/alivyn demo tui` | Available | The earlier Bubble Tea rendering probe remains available separately. |
| `alivyn model key import` and `model check` | Passed on macOS arm64 | A private `0600` key file was loaded with provider environment variables removed, and DeepSeek accepted a live `deepseek-flash` request. |
| `alivyn chat` | Passed on macOS arm64 | A short Chinese reply was generated by DeepSeek and saved in the local continuous conversation. |
| `CGO_ENABLED=0` cross-builds | Passed for macOS amd64, Linux amd64, and Linux arm64 | The prototype compiles without CGo for these targets; execution was verified only on macOS arm64. |
| `CGO_ENABLED=0 go build` | Passed on macOS arm64; binary approximately 11 MB | The prototype can be packaged as one executable. |

The automated model test uses a local mock server; the live DeepSeek check above is a separate manual smoke test. Replay tests parse supported interview phrases and run the same policy logic as the persistent runtime. The runtime writes only to a local test outbox and records its decisions. A Telegram bot, Feishu application, or installed background service has not yet been exercised. Conversation history and source-linked interview memory persist locally; broader memory extraction remains pending.

The module path is `github.com/AsCat/alivyn` to match the intended personal repository.
