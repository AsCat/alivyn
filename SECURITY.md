# Security Policy

Alivyn handles model credentials and potentially sensitive relationship history. Please do not disclose a suspected vulnerability in a public issue.

Before a public release, the repository will enable GitHub private vulnerability reporting and publish a maintainer contact method. Until then, report security concerns directly to the maintainer through an existing private channel.

The project is currently a foundation prototype and has no stable release. Security fixes and compatibility updates will be described in release notes once releases begin.
