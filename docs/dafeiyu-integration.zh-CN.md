# 大肥鱼机制吸收与意续路线

状态：2026-11-21 第一条心境行为链路已落地。对照 [whyever77/dafeiyu-astrbot](https://github.com/whyever77/dafeiyu-astrbot) 的 `main@64274354`。上游以 Python、AstrBot、NapCat 和 QQ 运行；意续以 Go 内核、飞书渠道和可替换的能力接口运行。借鉴机制时保留来源；如复制上游 MIT 代码，保留许可及署名。角色形象、声音和第三方服务分别核对授权。

## 原则

同一个人产生的状态应改变她的回复、主动联系、生活选择和未来的语音表达。一次聊天、一次世界事件或一次真实工具结果必须能回答“她为什么有这个变化”。无来源的猜测不写成经历；发送结果不写成“想发送”。用户的沉默不自动造成委屈或好感变化。所有模块共用事件来源、联系账本和权限回执，角色实例之间隔离。

## 路线与验收

| 阶段 | 吸收的机制 | 意续实现位置 | 验收条件 |
| --- | --- | --- | --- |
| 1 心境影响行为 | 上游 affective core 的连续状态、作息回归和表达联动 | `character.affect` 投影、已送达回复后的整理、内在唤醒、主动联系 | 同一段有来源的经历改变后续参与方式；时间流逝使短期冲动减弱；遗忘与重置清除影响；不会把内部数值说给用户 |
| 2 联系统一 | 上游生活分享与主动聊天共用联系账本 | 现有意续联系队列加入各来源提议和发送结果 | 普通主动聊天、生活分享共用勿扰、未回复、频率与去重；未知发送结果不盲重试 |
| 3 感知和表达 | 上游图片、语音理解与 TTS 链路 | Feishu 渠道、`perceive` 与 `express` 能力 | 图片或语音可追溯到真实附件；回复可发语音；失败时不声称已看见、听见或发送 |
| 4 自己的活动 | 上游生活目标、检查点、作品与 B 站活动 | 人物目标、事件账本、经授权的只读网页或媒体工具 | 同一目标跨天继续；每一步有来源和结果；没有内容可分享时安静结束；设备行动需单独授权与回执 |
| 5 观察界面 | 上游记忆星图和小小房间 | 同一事件流的只读客户端 | 时间线、图谱和角色活动与聊天所知一致；画面不反向编造经历 |

## 当前切片

`character_v2` 的后台整理现在可保存 `moment.affect`：愉快程度、活跃程度和当下社交趋向各是小范围内部值，并带 1–3 个现有来源 ID。它是这次已送达交流后的角色化解释，不是用户好感度。投影在两小时后降低活跃和社交趋向，八小时后失效；下一轮交流可以更新它。普通回复、内在唤醒与联系判断读同一状态，明确边界和眼前内容仍优先。缺失该字段的旧快照继续可用。

后续应把状态变化显式索引为可回放事件，并补充无新聊天时的生活事件更新；当前短时投影仍随 `character_turns` 保存。对自然度的判断需要用完整聊天轨迹比较，不用单句样例证明效果。上游某些生活功能在其 README 中标为本地实现、默认关闭或尚未完成真实联动验收，接入时按代码和运行证据逐项核对。

隔离模型试演的“低落心情延续”四轮均保存了有聊天来源的脉冲；普通回复在一段闲聊和明确的“不用找话题”后缩短。试演没有向真实飞书发送消息，也不能证明长期真人感。空白或类型错误的模型 JSON 会做一次有限重试；引用不存在的证据时仍拒绝保存。
