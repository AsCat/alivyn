# 项目命名记录：Alivyn · 意续

状态：用户已确认项目名称 Alivyn · 意续。日期：2026-10-23。

## 命名方案

**Alivyn** 是全球统一品牌、仓库名和 CLI 名称；**意续** 是中文名称。中英文文档分别以 `Alivyn` 和 `Alivyn · 意续` 呈现，但链接、包名和社交账号尽量统一为 `alivyn`。

`Alivyn` 读作 *AL-i-vin*，是一个可读作名字的自造词，让人联想到 *alive*。这种联想描述的是产品的拟人化体验，不代表声称 AI 具有真实生命或意识。

`意续` 中的「意」来自发起人的私人故事，也可以公开解释为心意、意图与主动性；「续」表示记忆、性格和关系历程不会随着一次会话结束。中英文分别表达同一个主题：**一个个体在对话之外仍有连续的状态，并能主动靠近用户。** 项目名称包含「意」，但默认角色不以任何现实人物为原型。

这是项目与运行时的名字，不强迫用户创建的 AI 个体使用同一个名字。个体可以叫任何名字，也可以是陪伴型或技术型角色。

## 对外表达

- 英文定位：**An open-source AI presence that remembers, grows, and reaches out.**
- 中文定位：**一个有连续记忆、会在合适时机主动联系你的开源 AI 个体。**
- 中文短句：**意有所向，故事未完。**
- 英文类别词：**persistent, proactive AI presence**。
- 中文类别词：**持续存在的主动型智能体**。
- 本地仓库目录及命令前缀：`alivyn`。计划使用个人 GitHub 仓库 `AsCat/alivyn`；[品牌初筛](./brand-availability.md)记录了其他账号和域名占用。

## 命名过程中的中文备选

| 名称 | 优点 | 取舍 |
| --- | --- | --- |
| **意续**（已确定） | 包含「意」，强调持久记忆与关系；与 Alivyn 的持续存在感相通；作为二字词较易检索 | 是新造组合，第一次看到需要一句解释 |
| **意往** | 「意」主动向外，呼应 reaches out；读音也让人想到「以往」和记忆 | 更像出发或远行，对长期共在的表达较弱 |
| **意初** | 「意」与起点相连，适合讲项目发端的故事 | 重心在开始，不足以表现持续运行和主动联系 |

`意在` 的“意仍在”双关也很贴切，但已有[意在科技展示](https://www.cobd.cn/cases/70.html)使用这一中文品牌；`意生` 与英文 *alive* 关联直接，但已有[意生宠物](https://caifuhao.eastmoney.com/news/20260721134843487489880)等相邻服务。两者暂不列入首选。

## 初步查重与局限

2026-10-23 的公开网页搜索中，未发现名为 `Alivyn` 的 AI 智能体、陪伴应用或软件项目。搜索到的同名用例包括一个[教育信托名称](https://indiankanoon.org/doc/172009841/)及个人网名。这个筛查只能说明没有发现明显的软件同名，不能保证商标、域名、GitHub 组织名、包名或应用商店名称可用。正式公开发布前须核查目标市场的软件相关商标类别与账号名称。

最初主推的 `Nianxu / 念续` 在中文语境里贴切，但 `xu` 的读音和拼写对国际传播形成额外门槛；后来根据发起人希望纳入「意」字的要求，将中文名称调整为「意续」。目前公开网页搜索未发现名为「意续」的同类 AI 产品；这仍不构成商标、软件名称或账号可用性的保证。考虑过的 `Remori` 已有[AI 日记应用](https://apps.apple.com/us/app/remori-journal/id6769155795)；`Avenlo` 已有[AI 角色聊天应用](https://play.google.com/store/apps/details?id=com.avenlo.mood.wede)，不宜作为本项目的英文名。
