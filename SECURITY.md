# Security Policy

Alivyn handles model credentials and potentially sensitive relationship history. Please do not disclose a suspected vulnerability in a public issue.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/AsCat/alivyn/security/advisories/new) or email the maintainer at [wengyanghui@foxmail.com](mailto:wengyanghui@foxmail.com). Please include reproduction steps without real API keys or private chat data.

Examples of relevant issues include credential exposure, unauthorized access to local history, unexpected outbound contact, and a way to bypass pause or quiet hours. If you can, include the affected commit or version, operating system, expected behavior, and a minimal reproduction using synthetic data. Please allow the maintainer time to investigate before public disclosure.

The project is currently a local preview and has no stable release. Security fixes and compatibility updates will be described in release notes once releases begin.
